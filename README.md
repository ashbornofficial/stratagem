Stratagem is a modern AI-powered study assistant designed to help users think critically, analyze arguments, and explore ideas in a deeper and more meaningful way. Built with Python and Flask, the application allows users to paste text and receive AI-generated analysis in multiple modes.

Whether you are studying a chapter, reviewing an article, or preparing for a debate, Stratagem helps transform passive reading into active intellectual engagement.

## Why Stratagem?

Traditional AI tools often summarize content. Stratagem goes beyond that by helping users:
- identify weaknesses in arguments
- challenge assumptions and hidden logic
- generate meaningful discussion questions
- connect ideas across unrelated disciplines

This makes it especially valuable for:
- students
- researchers
- educators
- critical thinkers
- lifelong learners

## Core Features

### 1. Find the Flaw
Identifies weak arguments, logical fallacies, hidden assumptions, and unanswered questions in the provided text.

### 2. Socratic Quiz
Generates conceptual, high-value questions designed to test understanding and encourage deeper reflection.

### 3. Connect Concepts
Links the input topic to ideas from other disciplines to reveal surprising patterns and cross-domain insight.
